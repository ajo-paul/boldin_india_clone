Welcome to the Developer Documentation for the **Boldin India Clone**. This platform provides holistic financial and retirement planning tailored to the Indian economic environment.

## Goal

Our goal is to give users actionable insights on how to retire successfully in India, utilizing models specific to Indian tax laws, investment instruments (EPF, PPF, NPS), and inflation metrics.

## Tech Stack

This project is built using modern, lightweight web technologies:
- **Framework:** Next.js 16.2 (App Router) with Turbopack for lightning-fast builds.
- **Language:** TypeScript 5 (Strict Mode).
- **Styling:** Tailwind CSS v4.
- **Documentation:** Fumadocs v16 (MDX, Static Generation).
- **Icons:** Google Material Icons (`material-symbols-outlined`).

## Key Features

1. **Hybrid Investment Modeling:** Start with simple "buckets" (Total Equity, Total FDs) to reduce onboarding friction, allowing users to drill down into specifics (like precise FD rates) later.
2. **Indian Financial Instruments:** Native support for EPF, PPF, NPS, and Indian Tax Regimes (Old vs. New).
3. **Advisor Portal:** A secure CRM layer for advisors to manage multiple clients, built securely into the application architecture.
